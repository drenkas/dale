# Dale Lenses

Choose one lens whose artifact can change the next decision; add one opposing
lens only for a different prediction or possible reversal. Skip when ordinary
reasoning suffices; brainstorm while goals or options are still forming.

Require a bounded question, system boundary, time horizon, error consequence,
and available evidence. Preserve phase: analysis authorizes neither planning
nor execution. Stay in this task unless evidence gathering is separately
authorized. Honor a named lens when it fits; explain mismatches and offer a
suitable method without silent substitution.

Separate observations, inferences, assumptions, preferences, and unknowns.
Never invent telemetry, probabilities, causality, constraints, or boundaries.

## Select

| Lens | Uncertainty | Artifact |
|---|---|---|
| causal | explanations or interventions | rival models and discriminating observation |
| systems | feedback, delays, recurrence | bounded feedback model and predictions |
| temporal | ordering, retries, concurrency, TTL | transitions and interleaving trace |
| conservation | missing/duplicated units or authority | balance equation and residual |
| invert | consequential failure paths | failure recipe, controls, tripwires |
| constraint | throughput resists local optimization | system constraint and migration signal |
| contradiction | coupled requirements | exact coupling and separation test |
| decide | costly uncertainty or irreversibility | options, regret, reversibility, information value |

Read only the selected section(s) of [lens contracts](references/lens-contracts.md).

## Apply and stop

Before interpreting new evidence, state method, artifact, and terminal condition.
Construct the artifact; preserve rival models and negative evidence. Set the
falsifier/update threshold before concluding. Prefer the cheapest safe observation
that distinguishes live models.

Return question, evidence boundary, lens, model, decision cruxes, terminal test,
decision impact, and material unknowns. Use `unidentified` for indistinguishable
models and `not applicable` when units, boundary, or falsifier cannot be defined.
Stop when the lens no longer changes the model, evidence need, or decision.
Plan or execute only when asked.
